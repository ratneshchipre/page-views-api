Welcome to official documentation of **Page Views API**. This is an open-source API that lets you track how many times a page is visited.

It stores view counts, avoids duplicate tracking, and lets you fetch results instantly.

## Usage

Understand how to use the API to track and fetch page view data in the following steps:

<Steps>

<Step>Track a View</Step>

Register a new page view for a specific site and path.

### Endpoint URL

```bash
https://page-views-api.ratneshc.com/api/v1/track?site=example.com&path=/
```

### Query Parameters

| Parameter | Type     | Required | Description                                                          |
| --------- | -------- | -------- | -------------------------------------------------------------------- |
| `site`    | `string` | Yes      | Your unique site identifier (e.g., `example.com`).                   |
| `path`    | `string` | No       | The page path to track (e.g., `/blog/hello-world`). Defaults to `/`. |

### Response

```json
{
  "success": true
}
```

### Examples

```typescript
await fetch("https://page-views-api.ratneshc.com/api/v1/track?site=example.com&path=/")
  .then(res => res.json())
  .then(console.log);
```

<Step>Get View Count</Step>

Retrieve the total view count for a specific site or page.

### Endpoint URL

```bash
https://page-views-api.ratneshc.com/api/v1/views?site=example.com&path=/
```

### Query Parameters

| Parameter | Type     | Required | Description                              |
| --------- | -------- | -------- | ---------------------------------------- |
| `site`    | `string` | Yes      | Your unique site identifier.             |
| `path`    | `string` | No       | Specific path to check. Defaults to `/`. |

### Response

```json
{
  "views": 1234
}
```

### Examples

```typescript
const res = await fetch("https://page-views-api.ratneshc.com/api/v1/views?site=example.com&path=/");
const data = await res.json();
console.log(`Total views: ${data.views}`);
```

</Steps>

## Script Based Tracking

For the simplest integration, you can use our tracking script. It automatically detects the page path and handles single-page applications (SPAs) like React or Next.js.

### Integration

Just add the following script tag to the your website:

```html
<script
  src="https://page-views-api.ratneshc.com/script"
  data-site="example.com"
  defer
></script>
```

### Features

- **Automatic Path Detection**: Automatically picks up the current `window.location.pathname`.
- **SPA Support**: Listens for route changes (History API) and re-tracks automatically.
- **Performance**: Optimized with `keepalive: true` to ensure requests complete even if the user leaves the page immediately.
- **Lightweight**: No dependencies, minimal footprint.

## Deduplication & Privacy

To prevent inflated numbers, we use a privacy-friendly deduplication mechanism:

- **Deduplication Window:** Views from the same visitor are only counted once every **30 minutes**.
- **Privacy First:** We don't store IP addresses. Instead, we generate a short-lived **SHA-256 hash** of the visitor's IP and User Agent to identify unique sessions.

## Rate Limiting

To ensure stability, the API is rate-limited:

- **Limit:** 60 requests per minute.
- **Scope:** Based on the client's IP address.
- **Automatic Normalization:** Our API automatically handles protocol removal, lowercasing, and trailing slash normalization for both `site` and `path`.
- **Failures:** Requests exceeding the limit will receive a `429 Too Many Requests` response.

## Error Handling

The API uses standard HTTP status codes:

| Status | Code                    | Description                                                 |
| ------ | ----------------------- | ----------------------------------------------------------- |
| `400`  | `Bad Request`           | Missing or invalid query parameters (e.g., missing `site`). |
| `429`  | `Too Many Requests`     | You have exceeded the rate limit.                           |
| `500`  | `Internal Server Error` | Something went wrong on our end.                            |

All error responses return a JSON object with an `error` field:

```json
{
  "error": "Missing or empty required query parameter: site"
}
```
