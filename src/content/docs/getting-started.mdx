## Installation

```bash
npm install page-views-api
```

## Usage

```typescript
import { PageViews } from "page-views-api";

const pageViews = new PageViews({
  apiKey: "YOUR_API_KEY",
});

const views = await pageViews.getViews({
  path: "/",
});

console.log(views);
```
